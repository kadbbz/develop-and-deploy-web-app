# 开发和部署轻应用的 OpenClaw 技能

## 项目背景

非专业IT人员借助 OpenClaw 开发一些小型的 Web 应用，如数据填报与汇总、审批流程、规则计算等场景时，经常遇到非功能需求遗漏、不规范等，甚至带来数据安全风险。希望通过这个技能，引导 AI 在统一的平台下，基于统一的脚手架完成轻应用构建。

## 平台功能

- 统一的用户存储，平台内一次注册，所有应用均可使用
- 统一的认证机制，支持basic认证
- 统一的用户注册机制，支持自行注册
- 应用间的数据、页面等需要严格隔离

## 脚手架功能

- 应用级的数据存取机制，普通用户有权限查看自己填报的内容
- 填报数据只需要可靠保存到应用自己的数据库中
- 解决数据结构的兼容性问题

## 开发者交互

- 需引导开发者提供非功能性需求的具体要求
- 提供可用的预览链接

## 技术方案

- 设计：huashu design
- 后端：express
- 数据库：nedb
- 前端：react
- 前端组件：ant design / ant design pro
- 图表组件：echart

## 实现视角

面向没有 IT 能力的普通业务人员，默认轻应用应优先解决固定规则计算、业务筛选、多人协作填报和状态跟进。

- 普通工作台：只承载填报、本人记录、固定规则结果、业务筛选和协作状态。
- 固定规则：由后端确定性计算并入库，前端可以同步预览，但不能只做展示层计算。
- 数据保存：填报结果写入 NeDB 数据库 `records.db`。
