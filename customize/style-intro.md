# LiteApp Style Intro

Use this style guidance together with `references/ui-style.md`.

## Mandatory Rules

- Favor a designed, editorial interface over a generic dashboard.
- Use a clear visual hierarchy and purposeful spacing.
- Keep the mobile layout intentional, not just compressed.
- Avoid purple-heavy defaults, flat white pages, and repetitive card grids.
- Let typography carry part of the product identity.

## Form-Specific Guidance

- Put the main task above the fold.
- Keep input labels explicit and calm.
- Use one strong call to action.
- Surface helper text only when it reduces ambiguity.

## Integration Rule

When a generated LiteApp includes this file, the app should treat it as the local style contract and follow it before introducing new UI patterns.
